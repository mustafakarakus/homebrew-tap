# Mustafakarakus Tap

## How do I install these formulae?

`brew install mustafakarakus/tap/<formula>`

Or `brew tap mustafakarakus/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mustafakarakus/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
